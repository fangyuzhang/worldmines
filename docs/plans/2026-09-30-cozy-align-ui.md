# 2026-09-30 UI 交互逻辑重构：向 CozySudoku 靠拢

> 参考：`reference/cozy-sudoku-1920.jpg`（CozySudoku 对局实机截图）
> 目标：把本项目的按钮**位置与形态**按 CozySudoku 的排布逻辑重排；CozySudoku 没有的按钮，
> 按其同类项的逻辑归位。已实现的部分在 §4 标注「已改」，其余为建议后续。

## 一、CozySudoku 的布局逻辑（从参考图读出的三条规则）

| 区域 | CozySudoku 放什么 | 抽取出的规则 |
|---|---|---|
| **顶栏左上** | `新游戏`（主操作按钮） | 主操作 / 导航放左上角 |
| **顶栏右上** | 一排**小图标**（信息·音乐·猫·调色板·手柄·显示·语言·设置齿轮） | **配置 / 全局类**收成一排图标，最右为设置 |
| **棋盘右侧** | 竖排**图标 + 文字**（印章·笔记·擦除·检查·撤销）+ 数字列 | **对局工具**竖排在棋盘右侧，图标 + 文字 |
| **左侧** | 猫 + 日期 + 大时钟 + 音乐播放器 | 「陪伴角落」独占左侧 |
| 棋盘 | 带标题栏的窗口（难度 No.XXXX 进度） | 进度信息贴在棋盘窗口上 |

**核心分化**：*配置* vs *对局工具* 分居两处——配置在顶栏右上一排图标，对局工具在棋盘右侧一列。

## 二、现状 vs 目标（逐屏）

### A. 对局 HUD（`ui/hud.gd`）——本轮主改

| 按钮 | 现状位置 | CozySudoku 对应位 | 目标位置 | 状态 |
|---|---|---|---|---|
| **关卡列表** | 左列（垂直居中） | 新游戏（左上主操作） | **顶栏排第一项 = 左上角** | ✅ 已改 |
| 雷数 / 时间 / 可断定 | 顶栏左（读数） | 棋盘标题栏进度 | 保持顶栏左 | 保持 |
| 教程（书本） | 顶栏左，紧贴雷数（契约 B9） | 信息 ⓘ（顶栏右上） | 保持顶栏左（见 §5） | 保持 |
| **设置（齿轮）** | 右列第 3 个 | 设置齿轮（顶栏右上最右） | **右上单排图标 col0** | ✅ 已改 |
| 换肤（调色板） | 右上第 1 行 col1 | 调色板（顶栏右上） | **右上单排图标 col1** | ✅ 已改 |
| 毛笔（绘画） | 右上第 2 行 col0 | —（工具类） | **右上单排图标 col2**（并入单排） | ✅ 已改 |
| **提示（灯泡）** | 右上第 1 行 col0 | 工具列（棋盘右侧） | **右列工具列第 1 项** | ✅ 已改 |
| 撤销 | 右列第 2 个 | 工具列末项「撤销」 | **右列工具列第 2 项**（补图标） | ✅ 已改 |
| 暂停 | 右列第 1 个 | —（CozySudoku 无暂停） | **右列工具列第 3 项**（补图标+文字） | ✅ 已改 |

**改动小结**：右上从**两行**（提示+换肤 / 毛笔）收成**一排**（设置·换肤·毛笔）；右列从
「暂停/撤销/设置」文字钮改为**图标+文字的对局工具列**（提示·撤销·暂停），**左列取消**，
`关卡列表` 上移到**左上角**（顶栏排第一项）；设置按 CozySudoku 归到顶栏右上配置区。

### B. 选关页（`ui/level_select.gd`，启动页）

| 按钮 | 现状 | CozySudoku 对应 | 建议 |
|---|---|---|---|
| 右上角：换肤·图鉴·设置 | 一排图标（3 枚） | 顶栏右上一排图标 | 已符合，保持 |
| 顶部：4 个页签 | 居中一排 | —（CozySudoku 无） | 保持 |
| Mod 页「模组管理」 | 页内顶部 | — | 保持 |

选关页已基本符合 CozySudoku「顶栏右上一排图标」的逻辑，**不改**。

### C. 暂停菜单（`ui/pause_menu.gd`）

CozySudoku 无暂停菜单（休闲游戏靠窗口叉号退出）。本项目保留「继续游戏 / 关卡列表」两个按钮的
居中弹窗 —— 与 CozySudoku 的窗口化弹窗隐喻一致，**保持**。

### D. 结算（`ui/game_over.gd`）

CozySudoku 胜利界面 = 皇冠 / 星星 / 进度。本项目无法比照（无此素材），按钮 `下一关 / 重新开始 /
跳过本关 / 撤回 / 返回关卡列表` 保持——但**建议**：把主推进按钮（`下一关`）做成强调色，
与 CozySudoku「主操作高亮」一致（本轮未改，列建议）。

## 三、CozySudoku 没有、但本项目有的按钮 —— 归位依据

| 按钮 | 为什么 CozySudoku 没有 | 归位依据 |
|---|---|---|
| 关卡列表 | CozySudoku 用窗口叉号退出 | 属「导航/主操作」→ 左列（对应新游戏位） |
| 提示 | CozySudoku 无提示 | 属「对局工具」→ 棋盘右侧工具列 |
| 撤销 | CozySudoku 有（工具列末项） | 直接对齐 → 工具列 |
| 暂停 | CozySudoku 无 | 属「对局工具」→ 工具列末项 |
| 毛笔（绘画） | CozySudoku 无 | 属「工具开关」→ 顶栏右上图标排 |
| 可断定读数 | CozySudoku 无 | 属「读数」→ 顶栏左（与雷数/时间同组） |
